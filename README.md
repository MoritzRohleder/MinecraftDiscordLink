# MinecraftDiscordLink

A server-side Minecraft mod that links a Minecraft server with a Discord server.
Supports **NeoForge** and **Fabric** from a single code base.

- Concept: [docs/CONCEPT.md](docs/CONCEPT.md)
- Specification: [docs/SPEC.md](docs/SPEC.md)

## Building

Requires Java 21.

```bash
./gradlew build
```

The mod jars are written to `fabric/build/libs` and `neoforge/build/libs`.
